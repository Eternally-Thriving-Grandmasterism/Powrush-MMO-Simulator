# Powrush-mmo-simulator

Human-playable web build of Powrush-MMO — the Sanctuary field, mercy-gated
harvest, PATSAGi councils, and a device-complete control layer.

Branched from the main lattice at
[Powrush-MMO](https://github.com/Eternally-Thriving-Grandmasterism/Powrush-MMO)
so wanderers can walk the expanse in a browser on phone, tablet, desktop, or
gamepad.

## Play

1. Enter the lattice and pick a faction.
2. Walk with the left stick or WASD.
3. Walk to a glow and **Tend** (Space / F / South).
4. Open **Allocate**, **Lineage**, **Climate**, or the council as the field asks.

Full binding table: [CONTROL_MAP.md](./CONTROL_MAP.md).

## Mercy gates

Every harvest is mercy-gated. Stressed nodes may be rested by PATSAGi. Origin
of a resource is observation, never ownership of a soul.
